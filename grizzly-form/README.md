# Проект: Форма анкеты для контакта

## Описание
Проект представляет собой веб-форму для сбора данных пользователей с фронтенд- и бэкенд-валидацией.  
Форма реализована с использованием Laravel 10, Bootstrap 5, HTML, CSS и JavaScript (Vanilla JS).

Пользователь может заполнить анкету, указав:
- Имя, фамилию (обязательные)
- Отчество (необязательное)
- Дату рождения (обязательная)
- Email (необязательный)
- Телефон(ы) с кодом страны (обязателен хотя бы Email или телефон)
- Семейное положение
- Информацию о себе (максимум 1000 символов)
- Согласие с правилами (обязательное)

После успешной отправки данные сохраняются в базу данных MySQL.

---

## Технологии
- **Backend:** Laravel 10 (PHP 8+)
- **Frontend:** HTML, CSS, Bootstrap 5, JavaScript
- **База данных:** MySQL
- **Дополнительно:** Ajax для асинхронной отправки формы

---

## Функциональность
1. **Фронтенд:**
    - Валидация всех полей на стороне клиента
    - Ограничение textarea до 7 строк
    - Динамическое добавление до 5 телефонов
    - Маски телефонов в международном формате
    - Активация кнопки "Отправить" только при корректном заполнении
    - Отображение ошибок под полями
    - Кастомные селекты для страны и семейного положения

2. **Бэкенд:**
    - Валидация данных на сервере через Laravel `Request`
    - Проверка: хотя бы Email или телефон должен быть заполнен
    - Сохранение данных в таблицу `contact_forms`
    - Поддержка Ajax-запросов с JSON-ответами
    - Отображение успешного сообщения после отправки

## Установка и запуск

1. **Клонировать репозиторий**
git clone https://github.com/VikaViktoriaK/grizzly-form.git
cd grizzly-form

2. **Установить зависимости**
composer install
npm install
npm run dev


3. **Настроить .env**
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=grizzly_form
   DB_USERNAME=root
   DB_PASSWORD=

4. **Создать таблицу contact_forms**
   php artisan migrate

5. **Запустить сервер**
   php artisan serve

6. **Перейти в браузере по адресу**
   http://127.0.0.1:8000/contact
